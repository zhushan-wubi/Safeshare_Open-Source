莫奈的秘密花园 - README.md
🌿 莫奈的秘密花园
一款治愈系私密分享平台，以水彩油画为视觉风格，主打隐私安全与情绪陪伴，让用户可以安心倾诉心事、封存秘密、分享心意。
核心定位：温柔、私密、治愈，所有数据本地存储，拒绝隐私泄露，为每一份情绪提供安全的安放空间。
📋 项目介绍
轻量级 web 应用，无需复杂配置，一键部署即可使用，贴合情绪倾诉场景，交互简洁友好，适合各类用户轻松上手。
核心优势：
- 隐私安全：数据本地存储，无云端上传，绝对保护用户隐私
- 情绪陪伴：AI 温柔回复，适配不同情绪状态，给予贴心反馈
- 功能全面：覆盖秘密分享、情绪树洞、时光胶囊等核心需求
- 轻量易部署：依赖少、启动快，新手也能快速上手
✨ 核心功能
1. 私密分享（核心功能）
- 可输入秘密、心事、寄语，设置 4 位以上访问密码
- 支持阅后即焚、24小时有效、7天有效三种过期模式
- 生成专属分享链接，复制即可分享，需密码才能查看
2. 情绪树洞
- 匿名倾诉烦恼，可设置匿名昵称，支持公开到心声墙
- 提交后可获得 AI 温柔回复，网络异常时也能正常使用
3. 时光胶囊
- 给未来的自己写一封信，可设置解锁密码和解锁日期
- 未到解锁日期无法查看，实现时光封存的仪式感
4. 双人秘密
- 双密码解锁机制，适合情侣、闺蜜等亲密关系共同查看
- 秘密内容加密存储，仅知晓两组密码的人可查看
5. 附加功能
- 支持5种情绪切换，AI 回复将适配对应情绪
- 实时字数统计，支持2000字以内内容输入
- 密码显隐切换、一键复制等便捷操作
📌 环境准备
依赖工具
- Python 3.7+（推荐 3.8-3.10）
- Flask 2.0+
- 浏览器（推荐 Chrome、Edge、Firefox）
🚀 安装部署步骤
1. 准备项目文件
将项目所有文件保存到本地同一目录，确保包含所需模板文件。
2. 安装依赖
打开终端，进入项目根目录，执行以下命令：
pip install flask
3. 启动服务
在项目根目录执行以下命令，启动 Flask 服务：
python app.py
启动成功后，复制终端显示的访问地址（默认：http://127.0.0.1:5000/），在浏览器打开即可使用。
4. 注意事项
- 首次启动会自动生成数据存储文件，请勿手动删除，否则会导致数据丢失
- 启动失败请检查 Python 和 Flask 版本是否符合要求
- 浏览器需清除缓存，避免旧页面样式/脚本冲突
📖 使用指南
1. 私密分享使用
1. 打开首页，选择当前情绪（可选）
2. 输入内容，设置访问密码并确认
3. 选择过期模式，点击生成分享链接
4. 复制链接和密码，分享给需要查看的人
2. 情绪树洞使用
1. 点击首页“情绪树洞”的“立即使用”，打开弹窗
2. 输入倾诉内容，设置匿名昵称（可选）
3. 勾选是否公开到心声墙，点击“投递树洞”即可
3. 时光胶囊使用
1. 点击首页“时光胶囊”的“立即使用”，打开弹窗
2. 输入内容，设置可选解锁密码和解锁日期
3. 点击“封存胶囊”，到解锁日期即可查看
4. 双人秘密使用
1. 点击首页“双人秘密”的“立即使用”，打开弹窗
2. 输入秘密内容，设置两组访问密码
3. 点击“创建秘密”，分享给对方即可共同查看
🔧 常见问题
Q1：启动服务后，浏览器打开显示 404？
A：检查项目文件是否齐全，重启 Flask 服务，确保访问地址正确。
Q2：提交内容后，刷新页面数据丢失？
A：检查数据存储文件是否生成，重启服务即可恢复。
Q3：AI 回复不显示/网络异常？
A：网络异常时，系统会自动使用本地备用回复，无需额外操作。
Q4：分享链接无法打开/密码错误？
A：确认链接完整、密码输入正确；若秘密已过期或被查看，会提示无法访问。
💡 温馨提示
- 请妥善保管分享密码和链接，丢失无法找回，秘密一旦销毁无法恢复
- 数据存储文件建议定期备份，避免误删导致数据丢失
- 本项目仅本地部署，仅当前设备可访问，保障隐私安全
